Maya has read the spec sheets. She knows an H100 has 80 GB of memory and that an L4 is cheaper. But numbers like “3.35 TB/s” still mean nothing to her. Why does that number matter so much? What is actually inside the box?

**Kai** looks after the data center where Maya's GPUs run. Kai is an infrastructure engineer: the person who keeps the machines powered, cooled, connected and healthy. Kai offers Maya a tour.

## The trip of one request

Priya, one of Botley's users, types: “Find me a flight to Lisbon on Tuesday.” Here is where that message goes.

<Sketch name="im-ch01-1" />

1. **Priya's phone** sends the message over the internet.
2. **The internet** carries it to the right building. If Priya is on the other side of the world, the trip there and back alone takes a noticeable part of a second.
3. **A data center** receives it. Inside the building, messages move between machines in well under a millisecond.
4. **A server**, one of thousands of computers in the building, runs Botley's code. Botley decides it needs the model.
5. **A GPU** in another server reads the request and writes the answer, one token at a time.
6. **The answer** travels all the way back to Priya's phone.

<Note>

Rough timings from Jeff Dean's well-known list of “numbers everyone should know”: a round trip inside one data center takes about 0.5 milliseconds, and a message from California to the Netherlands and back takes about 150 milliseconds. The list is from 2009, so treat the numbers as rough sizes, not exact values.

</Note>

## Zooming in

Each stop in that trip is a box inside a bigger box. A data center holds rows of racks. A rack holds servers. A server holds GPUs. A GPU holds thousands of tiny workers.

<Takeaways>

- A request travels from a phone, over the internet, into a data center, to a server and a GPU, and back.
- A round trip inside a data center takes well under a millisecond. Across the world, it takes a noticeable part of a second.
- A data center holds racks, racks hold servers, servers hold GPUs, and GPUs hold thousands of tiny workers.
- Everything in a data center exists to keep the GPUs busy.
