NVIDIA GPUs are the most common choice, but they are not the only AI chips. Each cloud has built its own, and AMD makes GPUs too. They all follow the same ideas from this notebook: lots of simple workers, fast memory right next to them, and fast links between chips.

## Why choose something other than NVIDIA?

- **Price.** A cloud's own chips can cost less for the same work, especially on that cloud.
- **Availability.** When NVIDIA GPUs are hard to get, other chips may be free.
- **Memory.** AMD's Instinct chips have a lot of memory per chip, which helps big models fit.

## The catch: software

Most AI software is built and tested first on NVIDIA GPUs, using CUDA. Other chips need their own software: AWS chips use the **Neuron** tools, Google TPUs use JAX, PyTorch with XLA, or vLLM's TPU support, and AMD uses **ROCm**. Many popular models and tools work on them, but not all, and not always on day one.

<Careful>

**Check your software first.** Before you choose a non-NVIDIA chip, check that your model, your serving tool (for example vLLM) and the features you need are supported on it. Then measure speed and cost with your own requests.

</Careful>

## AI chips in laptops and phones: NPUs

Many new laptops and phones include an **NPU** (neural processing unit), a small, low-power AI chip:

| Device chip | NPU speed |
|---|---|
| Apple M4 | 38 trillion operations per second |
| Qualcomm Snapdragon X Elite | up to 45 trillion |
| Intel Core Ultra (Series 2, Lunar Lake) | up to 48 trillion |
| Microsoft's requirement for a Copilot+ PC | at least 40 trillion |

NPUs suit small models that run on the device: live captions, translating speech, blurring a video background, or a small assistant that works offline. They can't run large models like the ones behind most agents. They share the laptop's normal memory, which is usually smaller and much slower than a data center GPU's memory (Chapter 7).

<NoSillyQuestions>

<QA q={"Are TPUs and Trainium GPUs?"}>

Not exactly. They are chips designed only for AI math, without the graphics history. But they follow the same ideas: many simple workers, fast memory nearby and fast links between chips.

</QA>

<QA q={"Could Botley run on a laptop NPU?"}>

Botley's code could, and a small model might. But a capable model for an agent like Botley needs far more memory and memory speed than an NPU has. Botley's model belongs in a data center.

</QA>
