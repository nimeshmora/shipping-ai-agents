| Word | What it means |
|---|---|
| Bit | One on/off switch, written as 1 or 0. |
| Byte | 8 bits. Enough for 256 different patterns. |
| Transistor | A tiny switch that electricity turns on or off. Chips are made of billions of them. |
| Floating-point number | A number with a decimal point, stored as a size part and a digits part. |
| FP32, BF16, FP8, FP4 | Number formats using 32, 16, 8 and 4 bits. Fewer bits: less memory, rougher numbers. |
| CPU | The chip that runs a computer's programs. A few clever cores. |
| Core | One worker inside a chip that follows instructions. |
| Clock speed, GHz | How many ticks per second a chip's clock makes. 3 GHz is 3 billion ticks a second. |
| Instruction | One tiny step in a program, such as “add these two numbers”. |
| Cache | Very small, very fast memory inside a chip. |
| Memory, RAM | Where a computer keeps what it is working on now. Fast, but cleared when the power is off. |
| SSD | Fast storage that keeps data when the power is off. |
| PCIe | The connection between a GPU and the rest of the computer. |
| Multiply-and-add | Multiply numbers by weights and add them up. Most of a model's work. |
| Layer | One step of a model. Many of the sums inside it can run at the same time. |
| Parallel work | Work that can be split into pieces done at the same time. |
| GPU | A chip with thousands of simple cores, built for parallel work. |
| Streaming multiprocessor (SM) | One station inside a GPU, with its own cores, Tensor Cores and small fast memory. |
| Warp | A team of 32 GPU cores doing the same instruction together. |
| Tensor Core | A part of a GPU that does a whole grid of multiply-and-adds in one go. |
| FLOPS, TFLOPS | Floating-point operations per second. Tera means a trillion. |
| Dense, with sparsity | Dense is the normal speed. “With sparsity” is twice that, and only for specially prepared models. |
| HBM | High bandwidth memory: memory stacked right next to the GPU chip, very fast. |
| GDDR | Graphics memory on separate chips around the GPU. Cheaper, slower than HBM. |
| Memory bandwidth | How many bytes per second can flow from memory to the cores. |
| Batching | Using each delivery of weights to write tokens for many users at once. |
| Tensor parallelism | Splitting one model across several GPUs, each holding a slice of every layer. |
| NVLink | NVIDIA's fast direct link between GPUs. |
| NVSwitch | A chip that lets every GPU in a group talk to every other at full NVLink speed. |
| HGX | NVIDIA's board of 8 GPUs joined by NVSwitch. |
| Rack | A tall cabinet holding many servers. |
| CUDA | NVIDIA's way of writing programs for its GPUs. |
| KV cache | The model's notes on the conversation so far, kept in GPU memory. |
| kW (kilowatt) | A measure of power. A kettle uses about 1.5 to 3 kW. |
| Liquid cooling | Cooling chips with liquid flowing through metal plates on top of them. |
| Quota, capacity | Quota is permission to use GPUs. Capacity is GPUs actually being free. |
| TPU, Trainium, Inferentia | AI chips made by Google (TPU) and AWS (Trainium, Inferentia). |
| NPU | A small, low-power AI chip inside laptops and phones. |
