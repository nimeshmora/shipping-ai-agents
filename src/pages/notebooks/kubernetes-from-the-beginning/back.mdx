| Word | What it means |
|---|---|
| Kubernetes, K8s | Software that runs containers for you across a group of machines. |
| Cluster | A group of machines that Kubernetes looks after as one. |
| Node | One machine in a cluster. It can be a real machine, a virtual machine or, with kind, a container. |
| Desired state | What you have asked Kubernetes to run, written in YAML files. |
| Actual state | What is really running right now. |
| Controller | A small program that compares the desired state with the actual state for one kind of thing, and fixes any difference. |
| Control plane | The parts of Kubernetes that make decisions: the API server, etcd, the scheduler and the controllers. |
| Worker node | A node that runs your own containers. |
| kube-apiserver, API server | The part of Kubernetes that every request goes through. kubectl talks to it, and so does every other part. |
| etcd | The database where Kubernetes stores the desired state. |
| kube-scheduler | Picks a node for each new pod. |
| kubelet | A program on every node that starts the containers for that node and watches them. |
| kind | A tool that makes a Kubernetes cluster out of Docker containers. |
| kubectl | The command you use to talk to a cluster. |
| Context | A kubectl setting that says which cluster to talk to. |
| Namespace | A named area inside a cluster that keeps things apart. Your own things go in `default`. |
| Pod | The smallest thing Kubernetes runs. It holds one container, or a few that need to live close together. |
| Registry | A place where images are stored, so nodes can download them. |
| `ErrImagePull`, `ImagePullBackOff` | The node couldn't download the image, and is waiting longer and longer between tries. |
| Deployment | Keeps a set number of pods running from a template, and moves them to new versions safely. |
| ReplicaSet | Made by a Deployment. Keeps the right number of pods for one version of the template. |
| Label | A name: value tag on a pod, such as `app: botley`. |
| Selector | A rule that picks things by their labels. |
| Service | One name and one address for a group of pods, which shares requests between them. |
| Cluster IP | A Service's address. It only works inside the cluster. |
| DNS | Turns names into addresses. In a cluster, coredns does this. |
| EndpointSlice | The list of pod addresses behind a Service. |
| `port`, `targetPort` | The port callers use on a Service, and the port the app listens on inside the pod. |
| ConfigMap | A named list of settings stored in the cluster. |
| Secret | Like a ConfigMap, for passwords and keys. Values are written in base64, which is not encryption. |
| base64 | A way of writing any data with plain letters and numbers. Anyone can turn it back. |
| Rolling update | Replacing pods with a new version a few at a time. |
| Revision | One version of a Deployment's pod template. |
| Probe | A check the kubelet runs on a container again and again. |
| Readiness probe | Decides whether a pod gets traffic. |
| Liveness probe | Restarts a container that has stopped working. |
| Startup probe | Gives a slow app time to start before the other probes run. |
| Taint | A mark on a node that keeps pods away, unless they say they accept it. |
| Requests | How much CPU and memory the scheduler sets aside for a container. |
| Limits | The most CPU and memory a container may use. |
| Millicore (`m`) | A thousandth of a CPU core. `250m` is a quarter of a core. |
| `Mi`, `Gi` | Mebibytes and gibibytes. `128Mi` is 128 × 1,048,576 bytes. |
| Pending | The pod has no node yet, usually because no node has room for it. |
| OOMKilled | The container went over its memory limit and was killed. Exit code 137. |
| QoS class | Guaranteed, Burstable or BestEffort. Decides which pods go first when a node is short of memory. |
| Gateway API | The Kubernetes API for getting requests from outside the cluster to the right Service. |
| CustomResourceDefinition, CRD | Adds a new kind of object to a cluster. The Gateway API's kinds are added this way. |
| GatewayClass | Says which software runs Gateways, such as Envoy Gateway. |
| Gateway | One entry point to the cluster, and what it listens for, such as HTTP on port 80. |
| HTTPRoute | Says which web requests go to which Service. It is attached to a Gateway. |
| Envoy Gateway | One program that runs Gateways. It starts an Envoy proxy for each Gateway. |
| Proxy | A program that takes requests and passes them on to somewhere else. |
| `Host` header | The part of a web request that says which name it was sent to. |
| Weight | How big a share of requests a route sends to each Service. |
| Ingress | The older API for the same job as the Gateway API. It still works, but nothing new is being added to it. |
| Debugging, `kubectl debug` | Finding out what's wrong. `kubectl debug` adds a short-lived container, with your own tools, to a running pod. |
| CrashLoopBackOff | The container keeps stopping, and the kubelet waits longer and longer before starting it again. |
| Exit code | The number a program leaves behind when it stops. 0 means all went well, 1 usually means the app's own error, 137 means it was killed. |
| Event | A short note Kubernetes keeps about something that happened to an object. Kept for about an hour. |
| BusyBox | A tiny image with many small Unix tools in it. |
| metrics-server | Measures how much CPU and memory each pod and node is using. `kubectl top` and the HPA need it. |
| HorizontalPodAutoscaler, HPA | Changes the number of replicas to keep usage near a target. |
| Utilization | How much a pod uses, as a percentage of what it requests. |
| Cluster autoscaler, Karpenter | Add nodes when pods are Pending, and remove nodes that are almost empty. Used on cloud clusters. |
| KEDA | A tool that scales pods on other numbers, such as the length of a queue, and can scale to zero. |
| VerticalPodAutoscaler, VPA | Changes pods' requests and limits, so each pod gets bigger or smaller. |
| Managed Kubernetes | EKS, GKE or AKS: the cloud runs the control plane for you. |
| SIGTERM, SIGKILL | “Please stop” and “stop now”. Kubernetes sends SIGTERM, waits 30 seconds, then sends SIGKILL. |

### Chapter 1, Sharpen your pencil

- When the machine is full, there's nowhere to put more copies.
